# Queens - Empowering Women to Achieve Financial Freedom

**Queens** is a platform designed to empower women by providing opportunities to make money through online ventures, career coaching, and community support.

## 🌟 Project Purpose
The **Queens** website was created to help women explore financial opportunities and build a supportive community where they can thrive.

## 📂 Project Structure
The project includes the following files:
- **index.html** – The main homepage of the website.  
- **style.css** – The stylesheet for styling the website.  
- **submit_form.php** – A PHP script for handling contact form submissions.  

## 🚀 Features
- **Informational Sections:** About, Services, and Contact.  
- **Contact Form:** Users can send messages through a contact form.  
- **Ad Monetization:** Planned integration with PropellerAds for revenue generation.
